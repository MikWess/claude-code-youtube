04 / 09
the player

YOUTUBE
IFRAME API.

loaded from a <script> tag in index.html. wrapped in a hook. exposes two methods that matter: playVideo() and pauseVideo(). that's the whole contract.

// useYouTubePlayer.ts const { containerRef, play, pause } = useYouTubePlayer('dQw4w9WgXcQ'); // App.tsx ytRef.current?.pause(); // claude is talking ytRef.current?.play(); // your turn again
